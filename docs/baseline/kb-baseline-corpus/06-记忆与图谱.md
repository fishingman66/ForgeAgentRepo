# 长期记忆与知识图谱

## 1. 记忆分层

长期记忆分六层：会话摘要、运行期工作记忆、事实记忆、消息归档、遗忘治理、向量检索。
会话摘要按消息水位滚动生成，只累积摘要不重复读全文；工作记忆存在缓存里，按运行编号隔离；
事实记忆落表并带事实键，同一事实键的新值会替换旧值而不是追加。

## 2. 召回与注入

记忆注入按重要性、时间衰减、命中次数三者混合打分，得分高的先注入，总体上受上下文预算约束。
命中次数同时用于节流，避免一条老记忆因为被反复命中而长期占据预算。
预算不够时优先保留系统提示词与最近对话，记忆块是最后被裁剪的部分。

## 3. 归档与遗忘

消息归档按时间分批迁移到归档表，主表只保留近期数据，归档表按月份分区。
遗忘是级联操作：先删记忆条目，再删关联的向量与图谱节点，最后确认归档表里也没有残留。
用户级遗忘必须二次确认，确认参数写错时接口会直接拒绝并给出明确提示。

## 4. 知识图谱

图谱有两类范围：Agent 级与工作空间级。同一条边在范围内的用户维度可以共享，共享级用用户编号零表示。
节点按名称去重，边按起点、关系、终点去重，重复写入只更新权重与最近出现时间。
抽取失败的片段会被跳过并计数，不会让整篇文档的抽取全部作废。

## 5. 配额与治理

知识库与记忆都可以配置配额，写入前先做配额校验，超限时按得分最低的先淘汰并归档。
过期条目按天扫描，到期直接归档而不是物理删除，保留可追溯性。
治理动作只改数据库行并让缓存失效，不重建索引，因此代价与语料规模无关。
