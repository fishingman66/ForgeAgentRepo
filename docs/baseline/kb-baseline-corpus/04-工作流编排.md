# 工作流编排指南

## 1. 画布与节点

Agent 编排画布与审批流是两套引擎，前者面向一次大模型任务，后者面向 OA 审批，两者零依赖、不要混用。
内置节点有十二类：开始、结束、大模型、工具、知识库、HTTP、代码、条件、循环、并行、汇聚、审批。
画布支持试运行，节点会按真实执行顺序逐一点亮；试运行可以指定起跑节点，也可以关掉外部调用只验证图结构。

## 2. 失败策略

每个节点可以单独配置失败策略，取值有终止整个流程、继续执行并给默认输出、跳转到指定节点三种。
重试次数上限为三次，重试间隔不超过五秒，节点级超时要小于流程级超时。
节点被取消或超时之后禁止再重试，这是为了防止带副作用的节点重复写入。

## 3. 变量与插值

节点输出可以通过点路径取值，写法是双花括号加路径，例如取某个节点的输出字段，数组用方括号加下标。
条件节点支持八种运算符，比较时优先匹配长运算符，其次优先按数字比较；不支持的表达式会直接报错而不是静默放行。
并行分支的结果按分支起点顺序合并，同名变量保留先完成者的值。

## 4. 触发方式

支持三种触发：手动执行、定时触发、外部接口调用。定时触发的幂等键由触发器 ID 与调度分钟组成，
同一分钟内重复调度只会执行一次。外部接口调用需要空间级密钥，请求体上限 256KB，响应超过 64KB 会被截断。
接口层面的限流分三层：IP 预限流、密钥级限流、端点级限流。

## 5. 与对话的关系

对话可以绑定工作流，模式有三种：关闭、每轮自动执行、按意图路由。
自动执行模式下每轮对话都会先跑一遍工作流，工作流的输出就是回答；
意图路由模式只在问题命中工具或知识意图时才走工作流，否则回到普通推理。
工作流执行失败不会降级成普通推理，这是为了避免同一轮对话被计费两次。
