# 知识库使用手册

## 1. 建库与选模型

新建知识库时要选嵌入模型。生产环境必须配置真实的向量模型，内置的伪向量只用于本地联调，
它的输出不具备语义准确性，在生产 profile 下对正式知识库会被直接拒绝。
向量维度由模型实际输出决定，不同知识库可以用不同维度的模型，集合会按维度分开存放。

## 2. 分块参数

分块大小默认 500 个字符，重叠 50 个字符。分块太大会让一个块里混进多个主题，召回时整块带进上下文会稀释信号；
分块太小会把一句话切断，导致两边都搜不到。调整分块参数后必须重建索引，否则新旧分块会同时存在。

## 3. 父子分块

开启父子分块后，先按父块大小切分，再在每个父块内切子块，只有子块参与向量化与召回。
命中子块时把父块全文作为上下文注入，这样检索精度由子块保证，上下文完整性由父块保证。
父块默认 2000 字符，超过这个长度会让单次注入挤占其它资料的位置。

## 4. 重建与清理

重建索引会按代次写入新分块，全部成功之后才切换生效代次，最后清理旧代。
重建期间知识库照常可以检索，用的是旧代分块；重建失败只是新代作废，不会影响已经可用的内容。
删除文档是逻辑删除，分块与向量会一并清理，想彻底移除原始文件需要走物理清理流程。

## 5. 阈值与精排

相关度阈值只作用于可比分数，例如向量余弦相似度或者重排序模型的打分。
融合排名分的量级很小，拿绝对阈值去卡它会让召回结果整体消失。
重排序模型要在模型管理里先配置好，知识库只填模型名称；模型不可用时检索会退回粗排结果并记录降级原因。
